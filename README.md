# 🎮 Tic Tac Toe Game

A classic two-player Tic Tac Toe game built with vanilla JavaScript, HTML, and CSS. Players can enter their names, take turns making moves, and track scores across rounds.

URL : https://moatazahmed156.github.io/Tic-Tak-Toe/
---

## 🚀 Features

- 🧑‍🤝‍🧑 Two-player support with custom player names
- 🔄 Round-based score tracking for both players
- 🧠 Smart game logic to detect wins and draws
- 🔁 "Play Again" and "New Game" functionality
- 💡 Dynamic game state and UI updates without page reloads


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla DOM Manipulation)
